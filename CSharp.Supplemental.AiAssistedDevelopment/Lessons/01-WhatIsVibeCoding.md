```csharp
using System;

internal static class Program
{
    private static void Main()
    {
        Console.WriteLine("=== What Is Vibe Coding? ===");
        Console.WriteLine();
        Console.WriteLine("'Vibe coding' is the practice of describing what you want in plain");
        Console.WriteLine("language and letting an AI agent write the first draft of the code.");
        Console.WriteLine("The name is informal, but the workflow is increasingly mainstream.");
        Console.WriteLine();
        Console.WriteLine("What it is good for:");
        Console.WriteLine("  - Rapid prototyping: turn an idea into working code in minutes");
        Console.WriteLine("  - Boilerplate elimination: CRUD scaffolding, DTO classes, test stubs");
        Console.WriteLine("  - Exploring unfamiliar APIs faster than reading documentation alone");
        Console.WriteLine("  - Getting unstuck: a second perspective on a problem you've been staring at");
        Console.WriteLine();
        Console.WriteLine("What it is not:");
        Console.WriteLine("  - A replacement for understanding the code you ship");
        Console.WriteLine("  - A substitute for code review");
        Console.WriteLine("  - Safe for production security code, cryptography, or compliance logic");
        Console.WriteLine("  - Reliable in domains where you cannot validate the output");
        Console.WriteLine();
        Console.WriteLine("The mental model shift:");
        Console.WriteLine("  Traditional: write syntax -> get behavior");
        Console.WriteLine("  Vibe coding:  describe behavior -> review and refine syntax");
        Console.WriteLine();
        Console.WriteLine("The shift is real and useful. The professional obligations do not change.");
        Console.WriteLine("You own every line you deliver, regardless of who or what wrote it.");
    }
}
```
