The Mistake

Calling the Function Instead of Passing It

setInterval/setTimeout need a function reference as their first argument - something they can call themselves, later. Adding () calls the function immediately instead, and passes whatever it returns to setInterval in its place: 

function sayHi() {
    console.log("Hi!");
}

setInterval(sayHi(), 1000);   // sayHi() runs RIGHT NOW - its return value goes to setInterval

The counter above only ever reaches 1 - the single immediate call that happens the instant the setInterval(...) line itself runs, before setInterval even gets a chance to schedule anything. setInterval never actually received a function to call later at all, only whatever sayHi() happened to return - so nothing genuinely repeats, no matter how long you wait.

The Fix

Pass the Function Itself, With No Parentheses

Remove the (), and let setInterval call the function on its own schedule:

setInterval(sayHi, 1000);   // correct - sayHi itself is scheduled to run every second

This time, the counter climbs to roughly 3 over the same three-second window - once per second, exactly as intended. If a repeating interval "only fires once" or "doesn't seem to be repeating at all," a stray pair of parentheses like this is the very first thing worth checking.
