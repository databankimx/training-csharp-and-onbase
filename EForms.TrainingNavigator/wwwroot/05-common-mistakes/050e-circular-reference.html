The Mistake

A Handler That Re-Subscribes Itself

What happens when this button is clicked over and over?

function addHandler(element) {
    element.on("click", function () {
        // ... do the actual work ...
        addHandler(element);   // attaches ANOTHER handler, every time
    });
}

Click the button a handful of times and watch the "ran" count: it doesn't match the click count at all - it roughly doubles with every click, since each click runs every handler currently attached, and each one of those attaches yet another. A few dozen clicks in, this would already be running thousands of times per click - a classic case of an event handler that resubscribes itself instead of just running its logic directly.

The Fix

Subscribe Once, Run Directly

The same button, subscribed exactly once, with no re-subscription inside the handler at all:

element.on("click", function () {
    // ... do the actual work, and nothing else ...
});

Here, the "ran" count always matches the click count exactly, no matter how many times you click. .on() is for attaching a handler once, when the page loads (or when an element is first created) - not something to call again from inside the handler itself. If you find yourself calling .on() from within an event handler, that's usually a sign something has gone wrong.
