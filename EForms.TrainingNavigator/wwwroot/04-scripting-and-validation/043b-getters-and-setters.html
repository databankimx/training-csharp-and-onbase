Get vs. Set: No Arguments vs. One Argument

Most jQuery methods that read or write something follow the same rule: call it with no arguments to get the current value, or with one argument to set it.

CallDoes
$("#myField").val()Gets the value (same as document.getElementById("myField").value)
$("#myField").val("x")Sets the value to "x"

This same get/set pattern applies broadly - .text() and .html() for an element's contents, .attr() for an HTML attribute, .css() for a style property, and more.
