`.each()`, `.find()`, and `.parent()`

.each() runs a function once per matched element - the jQuery equivalent of the .forEach() array method from the JavaScript chapter. .find() searches within the matched elements, rather than the whole page. .parent() moves up from an element to its immediate container.

PO NumberAmount
PO-4471340
PO-4472120.5
PO-447375.25
 
$("#glTable .amount").each(function () {
    var amount = Number($(this).text());
    var row = $(this).parent();
    if (amount > 200) {
        row.addClass("over-limit");
    } else {
        row.removeClass("over-limit");
    }
});

$(this) inside .each() refers to whichever element the current pass is on - the same role this plays inside the constructor functions from the Functions lesson, just in a loop instead of a call to new. .addClass()/.removeClass() add or remove a CSS class, which is almost always a cleaner way to change an element's appearance than setting individual style properties directly.

`.append()`

.append() adds new content as the last child of the matched element - here, a whole new row at the end of the GL table above: 

$("#glTable tbody").append(
    "<tr><td>PO-4474</td><td class='amount'>250</td></tr>"
);

Try adding a few rows, then click "Highlight Rows Over $200" again above - the highlight logic runs against whatever rows currently exist in the table, including ones added afterward, since it searches the live DOM each time it runs rather than a fixed list captured once.
