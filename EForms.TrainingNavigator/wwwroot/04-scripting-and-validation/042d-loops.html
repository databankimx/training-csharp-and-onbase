for

Repeats a block a set number of times, tracking its own counter. The three parts - initializer, condition, and increment - are all declared together, up front: 

for (var i = 0; i < glAmounts.length; i++) {
    lines.push("Row " + (i + 1) + ": $" + glAmounts[i].toFixed(2));
}

while

Repeats a block for as long as a condition stays true, with no built-in counter - you manage that yourself. The condition is checked before each pass, so if it's already false the very first time, the loop body never runs at all: 

while (total < 500 && i < glAmounts.length) {
    total += glAmounts[i];
    i++;
}

do...while

The same idea as while, but the condition is checked after each pass instead of before - so the body always runs at least once, even if the condition was already false to begin with. This demo starts with a counter already past the array's end, to make that obvious: 

var i = 99; // already out of range
do {
    lines.push("Ran with i = " + i);
    i++;
} while (i < glAmounts.length);

for...of

Iterates over the values in an array (or any other "iterable") directly - no index variable to manage at all: 

for (var amount of glAmounts) {
    lines.push("$" + amount.toFixed(2));
}

for...in

Iterates over the keys (property names) of an object: 

for (var key in invoiceRecord) {
    lines.push(key + ": " + invoiceRecord[key]);
}
Don't mix these up: for...of is for arrays and gives you each value. for...in is for objects and gives you each key. Using for...in on an array will technically work, but gives you the array's numeric indexes as strings rather than the values themselves - almost never what you actually want. Use for...of (or a plain for loop) for arrays, and for...in for objects.
