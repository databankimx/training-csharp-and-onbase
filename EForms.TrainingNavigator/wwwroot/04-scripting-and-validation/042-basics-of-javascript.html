JavaScript is what makes an HTML page interactive rather than just static text and inputs - validating a field before it's submitted, computing a total as the user types, showing or hiding parts of a form based on an earlier answer, or reacting to a button click. Everything in this chapter builds on the HTML you've already learned; scripting is how that HTML actually comes alive.

This applies just as much to a plain HTML form on any website as it does to an OnBase e-form - the language itself doesn't change. What's specific to OnBase is covered separately in each lesson as it comes up: things like which JavaScript features are safe to rely on given OnBase's own rendering engine, and where OnBase expects scripts and event handlers to live on a form.

The lessons below cover the language fundamentals, one concept at a time - variables, operators, control flow, loops, functions, and the two structures (arrays and objects) nearly everything else builds on.
