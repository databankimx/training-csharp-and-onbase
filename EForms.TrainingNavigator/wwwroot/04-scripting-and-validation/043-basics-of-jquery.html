jQuery is a JavaScript library - not a separate language, just a set of functions built on top of everything covered in the Basics of JavaScript lessons, aimed at making common tasks (finding elements, reading and writing their values, handling events, and calling web services) shorter and more consistent across browsers than writing the equivalent plain JavaScript by hand.

$ is shorthand for jQuery - $.ajax and jQuery.ajax are the exact same thing. Nearly everything in jQuery follows one pattern: $(selector).method(args), where the selector works like a CSS selector.

OnBase forms have rendered using a Chromium-based engine since v22 (2022), so modern jQuery works without issue. Older documentation floating around may mention jQuery 2.x compatibility concerns - that only applied when OnBase rendered forms as Internet Explorer 9, prior to v22, and no longer applies.
