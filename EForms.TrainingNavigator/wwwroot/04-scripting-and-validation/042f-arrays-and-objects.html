Arrays

An array is an ordered list of values, indexed starting at zero:

var glRows = [
    { poNumber: "PO-4471", glCode: "6010", amount: 340.00 },
    { poNumber: "PO-4472", glCode: "6020", amount: 120.50 },
];

glRows[0].poNumber; // "PO-4471" - the FIRST item is index 0, not 1

A few of the array methods you'll reach for most often:

MethodWhat it does
.push(item)Adds an item to the end of the array
.forEach(fn)Runs a function once for each item
.map(fn)Builds a new array by transforming each item
.filter(fn)Builds a new array with only the items that pass a test

.map() and .filter() both return a brand-new array rather than changing the original - useful to know, since it means you can chain them, or keep the original list intact for later use.

Objects

An object is a collection of named properties - the most common way to create one is an object literal:

var invoice = {
    invoiceNumber: "INV-1042",
    vendor: "Acme Supply",
    amount: 1035.75,
};

invoice.vendor;      // dot notation
invoice["vendor"];   // bracket notation - same result

Dot notation and bracket notation access the same property - the difference is that bracket notation accepts a variable, letting you look up a property whose name you don't know until the script actually runs. Dot notation only accepts a literal name written directly in the code.

Comparing the Ways to Create an Object

By this point in the chapter, you've actually seen three different ways to create an object:

ApproachWhen to use it
Object literal { }A single, one-off object - by far the most common case, and what this lesson covers above
Constructor functionA reusable "template" for creating many similar objects - covered in the previous lesson
classA more modern, structured version of the constructor function pattern
OnBase note: as covered in the previous lesson, class only works on a current, Chromium-based OnBase installation - not on an older one still rendering forms with Internet Explorer 9. Object literals and constructor functions both work everywhere, on every OnBase version, which is why they're the patterns actually used throughout this training set rather than class.
