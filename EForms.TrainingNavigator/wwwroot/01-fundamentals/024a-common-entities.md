# Commonly Used HTML Entities

A quick-reference table of the entities you'll use most often: escaping HTML's own reserved characters (`&lt;`, `&gt;`, `&amp;`, `&quot;`, `&apos;`), a non-breaking space (`&nbsp;`), and the copyright/registered/trademark symbols (`&copy;`, `&reg;`, `&trade;`).

Each row shows the named entity, its numeric Unicode reference, the actual rendered character, and what it means. See the `024-html-entities` lesson for the general syntax rules these follow.
