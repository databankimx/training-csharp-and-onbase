HTML 5 Code Style Conventions

Declare the !DOCTYPE We will always use the HTML5 specification <!DOCTYPE html>
Use all lowercase for tags and attributes <span> not <SPAN>
<span class="spacer"> not <span CLASS="spacer">
Close all container elements <p> ... </p> not <p> ...
Do not use self-closing tags for object elements <br> not <br />
Surround all attribute values with quotes <span class="spacer"> not <span class=spacer>
Specify alt text and dimensions for images <img src="pic.png" alt="alt text" style="width:200px;height:100px;"> not <img src="pic.png">
Don't use spaces around equals signs <span class="spacer"> not <span class = "spacer">
Avoid long lines Since line-breaks are ignored in HTML, keep lines to less than 130 characters.
Indent child elements four spaces <p>
    <span> ... </span>
</p>
not:
<p>
<span> ... </span>
</p>
Include all of the required and recommended elements <htmllang="en-us">
<head>
    <meta charset="utf-8">
    <title> Page Title </title>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <!-- Note: Do not place any <script> or <style> tags after the </head> tag -->
</head>
<body>
</body>
</html>
