Special Characters in HTML

For a number of reasons, you will frequently need to add special characters to your HTML.

  • Characters such as <, >, ", etc. have special meanings in HTML and have to be escaped.
  • Accents and currency or foreign characters (á, €, α, etc.)
  • Special characters like ⇒, ♠, ©, etc.

The syntax for adding these is:

  • Named entity - e.g.: &lt; = <
  • Decimal numeric reference - e.g.: &#60; = <
  • Hexadecimal numeric reference - e.g.: &#x3C; = <
