Semantic Elements in HTML

In HTML, some elements (form, table, etc.) have semantic meaning.

That is, they not only tell the browser what to render, but explain to the developer the intent of the element.

Historically though, the fundamental components of the design (div, span, etc.) are only syntactic.

We understand how they are rendered, but we have to analyze the content to understand the intent.

In later versions of HTML, additional semantic tags were added to convey meaning to the developer.

These tags do not render differently than their syntactic counterparts.

However, they do make styling easier, improve accessibility for screen reader users, and provide consistent standards for use:

- For example: <main> instead of <div class="main">
Additionally, CSS frameworks, like Bootstrap use these semantic tags to enable dynamic styling.
