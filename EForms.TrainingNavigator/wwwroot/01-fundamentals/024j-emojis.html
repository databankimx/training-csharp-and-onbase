Emoji Entities

Like other symbols, emoji can be inserted into HTML using numeric character references - for example, &#128512; produces 😀. Most single emoji use one numeric reference, but many common emoji (skin tone variants, flags, and combined emoji like families or profession icons) are actually a short sequence of several codepoints joined together, sometimes with a zero-width joiner (&zwj;) between them.

The full Unicode emoji set is large - into the thousands, once every combination and sequence is counted - which makes it impractical to include as a table directly in this lesson.
