Here's a quote from the World Wide Web Consortium
The World Wide Web Consortium (W3C) is an international public-interest non-profit organization where Member organizations, a full-time staff, and the public work together to develop web standards. Founded by web inventor Tim Berners-Lee, W3C's mission is to make the web work for everyone. Contact W3C for more information.

The W3C's design principles are: Web for All & Web on Everything
