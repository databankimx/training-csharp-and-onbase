# Page Layout Elements

Building a responsive page layout (one that adapts to different screen sizes) can be done several different ways. This lesson is an index into the ones covered elsewhere:

- **CSS Frameworks** - pre-built CSS layout systems, covered in their own lessons:
  - [Bootstrap](https://www.w3schools.com/bootstrap/default.asp)
  - [W3.CSS](https://www.w3schools.com/w3css/default.asp)
- **CSS Float Layout** - the older technique, using the `float` property to position elements side by side (see the next lesson)
- **CSS Flexbox Layout** - a modern, purpose-built layout model for arranging items in a row or column (see the lesson after that)
- **CSS Grid Layout** - another modern layout model, for two-dimensional (row-and-column) layouts (see the lesson after that)

Flexbox and Grid are generally preferred for new work over float-based layout, which was originally designed for wrapping text around images, not full page layout, and requires more workarounds (like "clearfix" hacks) to use reliably for that purpose.
